XMTrading Gmail Intake

1. 本アプリについて

XMTrading Gmail Intake（以下「本アプリ」）は、所有者本人が自分の Gmail アカウントで利用する個人用アプリケーションです。 一般利用者向けのサービスとして提供するものではありません。

2. Google ユーザーデータへのアクセス

本アプリは Google OAuth を利用し、Gmail の読み取り専用スコープ https://www.googleapis.com/auth/gmail.readonly のみを要求します。 メールの送信、削除、変更を行う権限は要求しません。

3. 取得・利用する情報

本アプリは、所有者本人の Gmail 内で対象条件に一致するメールについて、次の情報を取得・処理する場合があります。

  • メッセージ本文および MIME データ
  • 送信者、受信時刻、Received ヘッダー等のメタデータ
  • メッセージ ID、Gmail history 情報、重複防止用のハッシュ値
  • 処理状態、監査・検証用のログ

これらは、対象メールの取得、重複防止、出所確認、分析、監査およびシステム検証のために利用します。

4. AI サービスへの送信

対象として選ばれたメール本文・ヘッダー情報・派生データは、自動分析のため OpenAI API に送信される場合があります。 一方、Google OAuth の client secret、access token、refresh token その他の認証資格情報は OpenAI API へ送信しません。

5. 保存

処理対象データおよび監査証拠は、所有者が管理するローカル環境または所有者が管理する保存先に保持される場合があります。 保存は重複防止、再現性、監査および障害調査のために行います。

6. 第三者提供・販売

本アプリは、Google ユーザーデータを広告目的で利用せず、販売しません。 自動分析に必要な範囲で外部 API へ送信する場合を除き、第三者へ提供することを目的としていません。

7. セキュリティ

OAuth 資格情報は分析処理から分離し、認証情報を AI モデルへ渡さない設計を採用します。 また、処理の重複防止、監査ログ、SHADOW 運用等の安全策を用います。

8. Google API Services User Data Policy

本アプリによる Google API から取得した情報の利用は、Google API Services User Data Policy （Limited Use requirements を含む）への適合を意図しています。

9. 変更

本ポリシーは、機能や運用方法の変更に応じて更新する場合があります。
