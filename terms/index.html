利用規約

XMTrading Gmail Intake

1. 適用

本規約は、XMTrading Gmail Intake（以下「本アプリ」）の利用条件を定めるものです。 本アプリは所有者本人が使用する個人用システムです。

2. 用途

本アプリは、所有者本人の Gmail に届く対象メールを読み取り、情報取得・分析・検証を補助する目的で使用します。

3. Google アカウントへのアクセス

本アプリは Gmail の読み取り専用権限のみを使用し、メール送信・削除・変更を行いません。

4. 外部サービス

本アプリは、Google APIs、OpenAI API その他の外部サービスを利用する場合があります。 これらのサービスには、それぞれの提供者が定める条件が適用されます。

5. 金融取引について

本アプリの分析結果は、特定の金融商品の売買を保証または推奨するものではありません。 現在の検証運用は SHADOW を前提とし、本ページおよび OAuth 認証機能は注文を実行するものではありません。

6. 保証

本アプリは検証中の個人用ソフトウェアであり、常時稼働、完全性、正確性または特定目的への適合性を保証するものではありません。

7. 規約の変更

本規約は、システム構成や運用方法の変更に応じて更新する場合があります。
