XMTrading Gmail Intake

所有者本人が利用する、Gmail 読み取り専用のイベント取得・分析補助アプリケーションです。

プライバシーポリシー 利用規約

目的

本アプリは、所有者本人の Gmail アカウントに届く指定メールを gmail.readonly の範囲で取得し、内容を自動分析ワークフローへ渡すための個人用ツールです。

Google データの利用

  • Google OAuth の権限は Gmail の読み取り専用スコープのみを使用します。
  • OAuth の資格情報や refresh token は、AI モデルへ送信しません。
  • 対象として選ばれたメール本文・ヘッダー・派生データは、自動分析のため OpenAI API に送信される場合があります。
  • 本アプリはメールの送信、削除、変更を行いません。
  • 本アプリは一般公開サービスではなく、所有者本人による個人利用を目的としています。

運用状態

現在は SHADOW（検証）運用を前提としており、本ページ自体は注文や取引を実行するものではありません。
